# website

This repository contains the source code for the UW Quizbowl website.

Contributions are welcome. Please use GitHub's [issues](https://github.com/quizbowl-uw/website/issues) and [pull requests](https://github.com/quizbowl-uw/website/pulls) features to report desired changes and submit code for review, respectively. Kevin Kodama's old guide to editing the website, which was made before this repository was created and details how to SSH directly into the website's host server to edit, has been moved to [`old-contributing.md`](./old-contributing.md).

Maintaining this website is the responsibility of the webmaster, an elected position outlined in the club's constitution. The current webmaster for the 2026-2 academic year is Yaj Jhajhria, who can be reached at [jhajhria@uw.edu](mailto:jhajhria@uw.edu).
